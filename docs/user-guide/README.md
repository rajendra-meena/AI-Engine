### Quick Reference

**Traffic Light System:**
- 🟢 Green = Good / Safe / Healthy
- 🟡 Yellow = Caution / Warning / Degraded
- 🔴 Red = Danger / Stop / Critical

**AI Decision Colors:**
- 🟢 BUY (with high confidence) = Consider buying
- 🔴 SELL (with high confidence) = Consider selling
- ⚫ NO TRADE = Wait, conditions not favorable

**Risk Colors:**
- 🟢 LOW = Normal trading
- 🟡 MEDIUM = Be careful
- 🟠 HIGH = Consider waiting
- 🔴 EXTREME = Do not trade
